# Buzzers — agent guide

## Commands
- `npm install` locally (`npm ci` in CI); Node >=20 required (`engines`; CI matrix 20/22/24).
- `npm run dev` / `npm run dev-server` (vite / `vite --host` for LAN multi-device).
- `npm run build` → `dist/` (gitignored) — verify after every change; `npm run preview` for built output.
- `npm run test:harness` (coop-on default) / `npm run test:harness:all` (`HARNESS_COOP=on` + `off`). CI on push/PR to main: `npm ci && npm run build && npm run test:harness:all`.
- `npm run episode-server` — standalone episode API on :3001.
- No typecheck/lint/format scripts exist.
- Env: `MONGO_URL` is server-only; without it the server refuses to start and cloud save/load buttons disable (file import/export still works). Dev proxies same-origin `/api` → :3001 with no config; prod needs its own `/api` route or `VITE_EPISODE_API_URL`. **Vite reads `VITE_*` at startup — restart dev after changing.** See `.env.example`.

## Layout / entrypoints
- `src/main.js` — the whole game (~18k lines): state, RPC, render assembly. Grep by function name; line numbers rot fast.
- `src/render.js` — resilient renderer (see Renderer). Keep it split from main.js.
- `src/episodes/*` (`api`/`editor`/`schema`/`ui`), `src/results/*` (`api`/`schema`), `test-episode-all-modes.json` fixture. `roadkill` and `fourway` are beta game kinds (`EPISODE_KIND_BETA`); `EPISODE_COOP_BLOCKED_KINDS` = fibbage/disorat/quixort/fourway. 4-Way content is episode-driven (host panel is read-only; producers can't control it).
- `src/snark.json` — `screen.group.key → {en,snark1,snark2}` with `{token}`. All player strings via `getSnark()`; it `escapeHtml`s vars — pass raw values (pre-wrapped `<strong>` double-escapes in snark modes; off mode returns the fallback as-is, so keep its inline HTML).
- `src/style.css` — flat CSS, custom properties, Segoe-first font stack. `body:has(...)` backgrounds are order-dependent; screw block is deliberately last (wins ties).
- `index.html` — `#app` + `#toast-layer` + `src/main.js` + footer.
- `vite.config.js` — VitePWA (`injectRegister:false`; custom registration in main.js) + dev-only `/api` proxy. `api/` = Vercel route handlers only — every file deploys, never put shared code there. `server/` = `core.js` (framework-free store ops), `index.js` (Express), `db.js` (Mongo adapter, serverless-cached, `__EPISODE_TEST_STORE__` test seam), `ratelimit.js`, `vercel.js`.
- `scripts/verify_avatars.py` — avatar asset checker. `test-harness/` — node ESM harness stubbing PlayroomKit + DOM, drives real RPC handlers.

## Architecture (non-obvious)
- **PlayroomKit**: `insertCoin({skipLobby:true, maxPlayersPerRoom:42})`; clear hash via `history.replaceState` first. Host is SSOT (`setState(k,v,true)` reliable); players → host via `RPC.call(…,RPC.Mode.HOST)`.
- **Round states** `IDLE → OPEN → LOCKED/ROULETTE → CLOSED → IDLE` (`ROUND_STATUSES`). Null-invariant: `coopControl`/`winnerCoopKey`/`correctOptions`/`correctAnswer` must be `null` (not dropped/undefined) in reset/open/close/finalize — otherwise signature + strict checks break.
- **Auth**: `producer-action` requires sender ∈ `producerIds` (else `{ok:false}`); screw victim-pick requires screwer or producer. Producer password is host-local only — `localStorage` `enc:v1:` AES-GCM (PBKDF2 from room code + origin); shared `producerPassword` is legacy, always wiped to null. Only host/producers render the code. `claim-producer` has no rate limit (accepted).
- **Crypto**: browser WebCrypto only (`crypto.getRandomValues`/`subtle`); never `node:crypto` (broke prod + harness). Unbiased PINs via `randomProducerPin()` (rejection sampling + `Math.random` fallback) — reuse, don't re-derive.
- **Host powers** (via `producer-action`): manual score adjust (NaN/zero no-ops, never non-finite), rename via `customNames` (blank clears), buzzer disable (`settings.disabledPlayerIds`), screw-block (`settings.screwBlockedPlayerIds`), kick/re-admit (`settings.kickedPlayerIds` — kicked can't buzz). Ids pruned after `HOST_PRUNE_GRACE_TICKS`=5; scores/names/rosters retained `HOST_RETAIN_TICKS`=300 so a rebooting device migrates home. `resetAllScores` writes `0` to every key incl. `team:*` (never deletes) + one `manual-reset` log entry so the signature flips.
- **Shared keys** (all `,true`): `settings`, `round`, `scores`, `gameLog`, `bingo`, `disordat`, `fibbage`, `quixort`, `roadkill`, `fourway`, `teamAssignments`/`teamSelect`, `controllerId`, `producerIds`, `customNames`, `credits`/`roomCodeSpotlight`/`analyticsSpotlight`/`episodePrompt` (host-written broadcasts, all in the signature), coop `coopRosters`/`coopMoods`/`coopLastCorrect`. `ensureHostInit()` seeds defaults, prunes departed ids (grace + unstable-snapshot guard — empty/halved rosters prune nothing), forces alliance when coop is on.
- **Rejoin identity**: PlayroomKit rotates pids, so each device keeps `buzzer_device_id` (localStorage) and links via the `link-device` RPC (sender-authenticated) + `deviceHash` broadcast. `deviceLinks` stores hashes only (cap 500, never absence-pruned). `reconcileDeviceLinks()` (host, every tick) migrates old-pid state to the single live owner per hash (scores **summed** on collision); 0 or 2+ live owners → no migration. Never auto-migrate by name (spoofable).
- **`getUiSignature()`** is the dirty-check for the 1s host tick / 250ms audience poll: scores + bounded `gameLogDigest` (id/awardedDelta/resolved/basePoints/result/scoreKey/roundId/type/option/answerText/playerId/coopKey) + coopLastCorrect/buzzCounts/presets + controllerId/producerIds/pendingLogId + the credits/roomCodeSpotlight/analyticsSpotlight/**episodePrompt** broadcasts + compact disordat/fibbage/quixort/roadkill/**bingo/fourway** summaries. **Any score/log/broadcast change must flip it** or remote screens go stale (their tick only patches timers). Never put full `gameLog` back in (unbounded stringify every 250ms/display).
- **Room-code spotlight** (`roomCodeSpotlight`): host CTA forces the mega modal onto audience displays; display-side badge/close only affects the local/auto modal — only the host ending it clears the spotlight. Producers never see the CTA.
- **Credits** (`credits`): host-written, tablet excluded, local dismiss per screen. Sections via `getCreditsPlayerSections()` — coop groups, else teams when team mode on (shared reads `team:*` total, alliance sums members, unassigned trail as their own section), else individuals.
- `updateTimerDisplays()` patches `data-*` timers without full render; also sets `data-timer-urgent` at ≤5s (500cs) — patch-only, never in the signature.
- **Timers**: handlers enforce wall-clock (`timeEndsAt`/`voteEndsAt`, `>=`); 1s `hostTick` only backstops. Unscrewed timer auto-releases at 60s (`activatedAt`); `startScrewTimer` won't extend a running one (`screwTimerEndsAt > now()`). 0 = no timer (`normalizeTimeOpen`); all timed surfaces share that convention.

## Renderer (never per-render rebinding)
- `render()` assembles HTML → `transitionMount` (250ms out/in, interrupts pending, respects `uiAnimationsEnabled`/`prefers-reduced-motion`). Mode keys change only between gamemodes.
- Delegated events: `bindEvents()` once (`delegatedBound`), `delegate(type,selector,fn)`; types registered before `#app` exists attach once it resolves (`initRenderer`/`getApp`). **Never add per-render listeners.**
- `scheduleRender(render)` coalesces callers into one rAF with input capture/restore; `renderImmediate` for prejoin only.
- Local-only UI state (modal flags, `coopEditing`) in module vars — never shared PlayroomKit state, or every screen mirrors one popup.
- `PRESERVED_INPUT_IDS` (render.js) + generic focused-input fallback (`[data-log-input]` keyed by entry id); no manual draft logic. `isEditingControl()` treats any focused input/select/textarea as editing (suppresses keyboard buzz/space).
- `setBuzzNotice` auto-toasts to `#toast-layer` (top-right, limit 3). No bottom notice bar.
- Score delta: `renderScores` emits `data-score-key`/`data-score-value`; `applyScoreDeltas` pill floats **above** the row; audience never shows deltas.
- Smooth timer is display-only; 1s `hostTick` authoritative.
- Buzzers-open background flash only with anims on (`body:not([data-ui-anims="off"]):has([data-buzzers-open])`) — the animation is the sole background color source, so gate it rather than just setting `animation:none`.
- CSS-only anim suite; gate every new anim behind `body:not([data-ui-anims="off"])` + the `prefers-reduced-motion` kill block.

## Coopertition (`settings.coopertitionEnabled`)
- Up to 3 sub-players/device; join name = group name; setup takes count + names (1P uses group name). Roster RPC `coop-roster`, edits gated by `coopAllowEdit`. Local drafts in `localStorage` (`buzzer_coop_*`), all access try/catch (private mode throws).
- Score keys: 1-slot device keeps `pid`; multi-slot uses `coop:{deviceId}:{slot}`. Group totals derived, never stored. Shrink freezes removed slots (still counted); grow folds orphaned `pid` into slot 0 (even zero balances, via `in`-check); toggle-off folds back; `ensureHostInit` prunes departed keys.
- Jeopardy control (`round.coopControl`): Q/B/P (2P Q/P) or BUZZ claims control (no log entry); shared grid unlocks only for the controller, pick attributed to controller then releases. Cleared on open/close/reset/roulette/timeout/ruling-reopen, released on holder departure. Slot clusters by `event.code`: P1 `QWEASD`, P2 `GHJVBN`, P3 `OP[L;'`; digits 1–8 work everywhere. Normal: diamond WASD/arrows (W→Y, A→X, S→A, D→B), grid QWEASD→1–6, list digits. Pure mappers on `__BUZZER_TEST__`: `getNormalOptionForCode`/`getDiamondOptionForCode`/`getGridOptionForCode`/`getCoopOptionForCode`/`getNumberKeyOption` (+ `renderNormalKeyLegend`/`renderCoopKeyLegend`). Hints only on the player buzzer card.
- Locks: screws banned at every layer (player RPC, `initiateScrew`/`selectScrewee`/`startScrewTimer`, `hostInitiateScrew`, host button); enabling coop clears a live screw. JACK hidden/coerced (`JACK_MULTIPLIER_OPTIONS` = 1/1.5/2/2.5/3, clamp in UI + `setHostSetting`); re-buzz off; options 4+; shared-team scoring → alliance; fibbage/disorat/quixort/**4-Way** blocked in UI **and** at RPC level. Mode/mode-toggle only from buttons/text; can't enable coop mid-fibbage/disorat/quixort/4-Way (Roadkill setup may wait with coop on; live Roadkill can't be flipped).
- Preset gate: coop without `lockAfterBuzz` needs a preset (`correctOptions`/`correctAnswer`) to open (`openBuzzers` + disabled button). Answer trimmed ≤120 chars; options integers within `optionCount`.
- Auto-rule: preset → wrong picks auto-deduct; none → unresolved for manual ruling. Bingo/disorat entries carry resolved `basePoints`/`awardedDelta`; ruling rejects non-finite deltas. Re-ruling reverses the prior screw mirror (`screwerScoreKey`/`screwerDelta`) instead of compounding.
- Correct-solution lockout is per-device: ruling positive appends the solving device's remaining slots to `buzzedPlayerIds`; other groups keep playing — **must run after all round writes** (stale `round` snapshot wipes it).
- Bingo/Wen coop-adapted (per-slot tracks, sibling lockout till next target, last-place auto-pick + host override). Fibbage/DisOrDat/4-Way have no coop model — keep it. Bingo trusts client `litIndex` by decision (forgery possible, accepted).
- Roadkill coop-supported: `guessed` keyed by score key; Q/B/P → `roadkill-buzz` with `coopSlot`; faces via `noteCoopLocalBuzz` + `coopMoods`. Can't enable coop during a live stream; setup may wait. No mobile exemption (global multi-slot block applies).
- Roulette device-level by decision (ceiling ÷ devices, device-keyed stops) with frozen roster (`expectedPlayerIds` snapshot at phase start): late joiners sit out, departs don't early-finalize, single-player target-leave finalizes at 0. Each group fields last-correct rep (`coopLastCorrect`). Animation loop is session-persistent (started once at login on every client, never self-clears) — `startRoulettePhase` calls it as backup only; **do not reintroduce self-clearing** (only the host would animate). `openBuzzers` with roulette method and no `finalValue` stays blocked (empty-player roulette goes straight to OPEN — set a value first).
- Faces: `public/avatars.md` spec (`{slot}-{buzz,dance,correct,wrong}.*`, filmstrips, frames auto-detected). Avatar GIFs/PNGs gitignored — fresh deploys 404-probe and fall back silently; rank-1 badge probe collides with `1.gif`. Lifecycle: buzz (optimistic local preview via `coopLocalBuzz`, then host log entry, holds while pending) → judged face → idle: correct self-clears ~1.5s, wrong holds till new round/reset (both flip to `rewind` mood, play backwards, then clear); buzz only for slots with a real log entry or fresh preview (never lockout siblings), one-shot faces only on owning device + host. Audience forced `idle`.
- Analytics post-round-only in coop: `renderAnalyticsCard` returns `""` unless round CLOSED (instant scoring would spoil correctness live).
- Mobile multi-slot blocked (`isMobileDevice`: coarse pointer + narrow); 1P exempt.

## Verification
- `npm run build` after every change. `npm run test:harness` before trusting multi-step logic — it drives real handlers and has caught stale-`round` overwrites and signature staleness that reasoning missed. Extend it for new multi-step flows.
- Harness stubs PlayroomKit + DOM; checks buzz/ruling math, edits, all game-mode gates, Roadkill + 4-Way setup/stream/scoring/finale/render in both coop modes, screw ban + victim-hijack rejection, non-producer rejection, roster accounting, roulette freeze, null-invariant, broadcasts, reset-all, credits grouping, episode-server owner password + size pre-check, host/player/audience HTML, no-render-warning. Dedicated `prod1` fixture drives all `producer-action` calls; player RPCs use `dev*`.
- Dual mode: `HARNESS_COOP=on|off` (default on); coop-only tests are `if (COOP)`-guarded, shared paths assert pid vs `coop:` keys. Mid-run toggles unconditional only when no-ops in the other mode.
- **Blind spots** (don't trust here): drops `,true` reliable flag, hardcodes `isHost`, `getElementById→null` (toasts/input preservation untested), `querySelectorAll→[]` (timer patch/deltas/smooth timer untested), keyboard events, mobile/`matchMedia`, avatar `Image` probing.
- **Symptom cheatsheet**: stale remote screens → signature missing the changed key; score NaN/frozen → ruling wrote non-finite; host button works but players blocked → UI-only gate, add server-side check in the RPC handler; static roulette → animation loop not restarted; "Not producer" → sender not in `producerIds`. **Never `Number(x || 0)` on ruling deltas** — masks NaN as 0 and silently resets resolved entries; normalize nullish first, reject non-finite after.

## Conventions
- Escape all interpolated names (`escapeHtml`); route strings through `getSnark()` + snark.json with raw vars.
- Keep the `render.js` and `test-harness/` splits as-is.
- Deliberately unchanged: roulette device-level economics, muted slots counting in totals, device-counted teams, bingo client-trust model, gitignored avatars, dead `getPlayerRank`/`getOrdinal` (delete if touched).
